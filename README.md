# My Dotfiles

Hii welcome, these are my dotfiles. Feel free to use anything you find useful.  
This repo is avilable on [my Codeberg] (main) and [GitHub] (mirror)

## Programs I use

- **os:** Artix
- **init:** OpenRC
- **WM/compositor:** *[dwl]*
- **statusbar:** *[dwlb]* + *[slstatus]*
- **terminal:** foot
- **menu:** rofi
- **editor:** neovim
- **browser:** Firefox ([user.js])
- **shell:** zsh

I also have configs for River, *[dwm]* and a few other WMs, however, they're very much not updated.
I have my own Firefox [user.js] based on [Betterfox] and [Arkenfox] with some things added.
Some ~useful~ scripts can be found in [.local/bin/].
Any forks can be found on my profile.
